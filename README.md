# Ballot.ng

A civic voting platform prototype for elections across Nigeria.

## Current status

The current version is a browser prototype with demo data stored in `localStorage`. The next step is connecting Supabase for secure authentication, election data, votes, roles, and audit logs.

## Run locally

```bash
node server.js
```

Then open http://localhost:3000.

## Environment variables

Copy `.env.example` to `.env` when backend integration begins. Real secrets must stay out of Git.
